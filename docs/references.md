# Research references

Last checked: **2026-08-08**.

This page prioritizes primary manufacturer/vendor documentation. Build logs are used to capture practical conflicts and sequence details that product pages omit.

## Primary / vendor sources

### KPower — RX-8 compatibility
https://kpower.industries/blogs/news/rx8-compatible-k-swap-components-now-available-from-kpower-industries

Key uses in this guide: tubular subframe fits RX-8, no rack spacers with NC rack, firewall work expected, NC hydraulic steering/standalone EPS, A/C option, intake/oil-pan/electronics guidance, S2 CAN caveat.

### KPower — RX-8 K-swap collection
https://kpower.industries/collections/04-11-rx8

Current RX-8-tagged parts/prices, including S2 radiator, electronics and displays.

### KPower — NC Race package
https://kpower.industries/collections/kpower-nc-mx5-swap-parts/products/kpower-nc-mx5-swap-kit-no-electronics

Used as a physical-parts list and cost benchmark. **Not represented here as a complete RX-8 kit.**

### KPower — NC complete package
https://kpower.industries/collections/items-with-lead-times/products/complete-kpower-nc-mx5-swap-package

Useful for component architecture and sensor/mount compatibility.

### KPower — USDM K24A water-pump housing
https://kpower.industries/products/usdm-k24a-water-pump-housing

Explicit JDM K24A/RBB accessory-drive distinction and conversion recommendation.

### KPower — RBB intake-side coolant neck
https://kpower.industries/products/k24a2-upper-coolant-neck-for-nc-mx5

Packaging-critical RWD coolant outlet.

### KPower — NC hydraulic power-steering kit
https://kpower.industries/products/k-swap-nc-power-steering-kit

### KPower — NC A/C kit
https://kpower.industries/products/k-swap-nc-air-conditioning-kit

### KPower — installation guides / basemaps index
https://kpower.industries/pages/installation-guides

Includes universal K24 harness guidance and NC K24 basemaps. The large NC PDF guide is linked there; it was not reproduced in this repository.

### Collins — K-series to RX-8 swap kit
https://collinsperformancetechnologies.com/products/honda-k-series-to-mazda-rx-8-swap-kit

Confirms K20/K24 to RX-8 5/6-speed application, included adapter/mount items and optional flywheel/rack/slave components.

### Collins — current RX-8 installation instructions
https://collinsperformancetechnologies.com/pages/honda-k-series-to-mazda-rx-8-install-instructions

Used for the retained-RX-8-transmission installation sequence, ABS/rack relocation, crossmember notch, cowl/firewall approach and bellhousing/starter clearance.

### Collins — RX-8 product collection
https://collinsperformancetechnologies.com/collections/mazda-rx-8

Current component-price reference.

### Collins — RX-8 CAN emulator
https://collinsperformancetechnologies.com/products/rx-8-wiring-emulator-for-canbus

Feature claims used only as a candidate integration path; S2 compatibility is explicitly left as a validation item.

### All4Swap — Mazda RX-8 CAN interface
https://all4swap.ru/product/rx8

Useful because its order form explicitly asks for chassis type/model year.

### 2009 RX-8 fuel-pressure service information (Operation CHARM mirror)
https://charm.li/Mazda/2009/RX8%202RTR-1.3L/Repair%20and%20Diagnosis/Powertrain%20Management/Tune-up%20and%20Engine%20Performance%20Checks/Fuel%20Pressure/Testing%20and%20Inspection/

Factory pressure test spec used to characterize the S2 fuel feed.

## Community / research aids

### RX-8 reverse-engineering repository
https://github.com/rnd-ash/rx8-reverse-engineering

Useful starting point for advanced CAN research. It should not be treated as a validated S2 swap interface without vehicle testing.

### RX8Club / Miata community transmission discussions
Community sources are useful for understanding the relationship between late RX-8 and NC Mazda transmission families, but the guide does not use that relationship to claim bellhousing interchangeability.
