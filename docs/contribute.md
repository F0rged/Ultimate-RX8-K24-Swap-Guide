# How to contribute to this site

Contributions are welcome when they make the guide more accurate, safer or easier to follow.

Useful contributions include verified fitment notes, completed-build evidence, vendor documentation, corrections to the bill of materials, clearer sequencing, photos or diagrams you have the right to contribute, and documentation for open questions.

Open a pull request against the repository with a short explanation of what changed and cite sources where possible. Safety-critical or fitment-sensitive changes should include the chassis, engine, transmission, steering setup and any relevant measurements.
