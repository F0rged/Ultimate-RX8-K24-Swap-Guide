# Research references

Last checked: **2026-08-08**.

This page prioritizes primary manufacturer/vendor documentation. Build logs are used to capture practical conflicts and sequence details that product pages omit.

| Claim | Source |
| --- | --- |
| KPower's RX-8-compatible tubular subframe fits the RX-8, does not require rack spacers with an NC rack, and still expects firewall work, steering, A/C, intake, oil-pan, electronics and S2 CAN planning. | [KPower Industries](https://kpower.industries/blogs/news/rx8-compatible-k-swap-components-now-available-from-kpower-industries) |
| Current RX-8-tagged KPower parts and prices include items such as the S2 radiator, electronics and displays. | [KPower Industries](https://kpower.industries/collections/04-11-rx8) |

| Collins confirms K20/K24-to-RX-8 5/6-speed application and lists included adapter, mount and optional flywheel, rack and slave-cylinder components. | [Collins Performance Technologies](https://collinsperformancetechnologies.com/products/honda-k-series-to-mazda-rx-8-swap-kit) |
| Collins' RX-8 instructions are used for the retained-RX-8-transmission sequence, ABS/rack relocation, crossmember notch, cowl/firewall approach and bellhousing/starter clearance. | [Collins Performance Technologies](https://collinsperformancetechnologies.com/pages/honda-k-series-to-mazda-rx-8-install-instructions) |
