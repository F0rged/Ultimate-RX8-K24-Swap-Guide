# Contributing

The goal is to turn this from a research synthesis into a repeatable RX-8 build manual.

A useful contribution should state:

- RX-8 model year / S1 or S2
- LHD or RHD
- transmission
- K engine code and head casting
- exact vendor/part revision
- measured dimensions where fitment is involved
- photos or diagrams you have rights to contribute
- what failed as well as what worked

For electronics claims involving ABS, DSC or EPS, "warning light is off" is insufficient. Document diagnostic communication and functional tests.

For prices, update the `checked_date` and preserve the old value in git history.
