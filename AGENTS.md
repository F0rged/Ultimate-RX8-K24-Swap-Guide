# Repository Instructions

## Build Guide Pages

These instructions apply to every chapter page in `docs/build-guide/`.

- Every chapter page must show chapter navigation directly below the breadcrumb and above the page title.
- The navigation labels must read `Last Chapter {chapter name}` and `Next Chapter {chapter name}` when adjacent chapters exist.
- Keep `docs/_data/build_chapters.yml` in sync whenever adding, removing, renaming or reordering build guide chapters.
